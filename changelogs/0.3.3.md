## Added

- Minecraft 1.21.10 support, on NeoForge 21.10.64 or newer, Forge 60.1.15 or newer, and Fabric with Fabric Loader 0.17.0 or newer and Fabric API 0.138.4 or newer.
- Minecraft 1.21.8 support, on NeoForge 21.8.54 or newer, Forge 58.1.22 or newer, and Fabric with Fabric Loader 0.16.13 or newer and Fabric API 0.136.1 or newer.
- Minecraft 1.21.5 support, on NeoForge 21.5 or newer, on Forge 55 or newer, and on Fabric with Fabric Loader 0.16.10 or newer and Fabric API 0.128.2 or newer.
- Minecraft 1.21.4 support, on NeoForge 21.4 or newer, on Forge 54 or newer, and on Fabric with Fabric Loader 0.16.9 or newer and Fabric API 0.119.4 or newer.
- Minecraft 1.20.4 support, on NeoForge 20.4 or newer, on Forge 49 or newer, and on Fabric with Fabric API 0.97.3 or newer.
- Minecraft 1.19.2 support, on Forge 43 or newer and on Fabric with Fabric API 0.77.0 or newer.
- Minecraft 1.18.2 support, on Forge 40 or newer and on Fabric with Fabric API 0.77.0 or newer.
- The 1.21.1 NeoForge jar also runs on Minecraft 1.21 with NeoForge 21.0 or newer, and the 1.20.1 jars also run on Minecraft 1.20, on Forge 46 or newer and on Fabric with Fabric API 0.83.0 or newer.

## Improved

- The map of the area around you that XaeroNav builds for routing uses about 40% less memory (at most about 270 MB instead of about 460 MB) and updates faster. Routes are unchanged.
- Walking lines on flat ground are drawn as straight lines instead of grid-shaped zigzags, so following them is shorter.
- When a shorter way is found as you get close to the destination on a long trip, the route now switches to it more readily.

## Fixed

- Starting deep underground no longer sends you on a long detour at depth before climbing up; the route now uses a nearby way up when there is one.
